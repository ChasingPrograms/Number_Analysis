## 📌 About

Number Analysis allows the user to enter multiple integers and performs several calculations and checks on each number.

The project was created as part of my Java refresher, with the goal of putting multiple concepts I had recently reviewed into practice in one program.

## ✨ Features

For each number entered, the program:

- Determines whether the number is odd or even
- Calculates the sum of all integers from 1 to the number
- Calculates the factorial using recursion
- Determines whether the number is prime
- Displays the results in a final analysis report
- Prevents negative numbers from being entered

## 🧠 Java Concepts Used

This project demonstrates:

- Variables and data types
- `Scanner` for user input
- Arrays
- `for` loops
- Enhanced `for` loops
- `while` loops
- Conditional statements (`if` / `else`)
- Methods
- Recursion
- Input validation
- Modulus operator (`%`)
- `long` integer values
